02 / MODEL NOTES

Know what the output means

The model is useful as a portfolio demonstration when its boundaries remain visible.

01 / DATA

Historical target

The saved model predicts a dataset field called “not fully paid.” That label does not establish when a payment was missed or whether a loan was formally in default.

02 / COVERAGE

Complete input mapping

The original app silently set omitted model fields to zero. This version collects every numerical field and maps one purpose category to the seven encoded columns.

03 / VALIDATION

Evidence still needed

The source dataset, reproducible evaluation, calibration, fairness review and current population checks must be supplied before any operational assessment.
